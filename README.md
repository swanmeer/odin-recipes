# odin-recipes

The goal of this project is to develop a simple website that consists of my favourite recipes
The home page contains a series of recipes, which directs us to the recipe when clicked on
Headings (h1 and h2) were frequently used for each title (Name of recipe, description,ingredients and steps)
The unordered list was used particularly for the ingredients, since they are not required to be in any specific order unlike the steps
The ordered list was used to outline the steps
The anchor element was used to connect the homepage with the recipes' page
